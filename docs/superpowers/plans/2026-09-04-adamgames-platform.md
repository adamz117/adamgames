# adamgames.site Platform Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the adamgames.site platform — Next.js app, Supabase accounts + stats database, shared site shell — and migrate the existing Flag Atlas game in as the first playable game, deployed live at adamgames.site.

**Architecture:** Next.js (App Router, TypeScript) serves a homepage stats dashboard, auth pages, and one route per game. Supabase provides email/password auth and a two-table Postgres schema (`profiles`, `game_stats`) behind Row Level Security. Flag Atlas — already a complete, tested standalone HTML/JS/CSS file — is embedded via an `<iframe>` rather than rewritten in React; a small `postMessage` addition lets it report progress to the Next.js page, which upserts it to Supabase when a user is signed in.

**Tech Stack:** Next.js 15 (App Router, TypeScript), Tailwind CSS (utility/layout only — brand colors are plain CSS custom properties so the plan doesn't depend on a specific Tailwind config syntax), `@supabase/supabase-js` + `@supabase/ssr`, Vercel hosting.

**Spec:** `docs/superpowers/specs/2026-09-03-adamgames-platform-design.md`

## Global Constraints

- Stack is fixed: Next.js App Router + TypeScript + Tailwind; Supabase (Postgres + email/password auth); Vercel + `adamgames.site` custom domain.
- Personal stats only — no leaderboards, no cross-user comparison, in this plan.
- No OAuth/social login in this plan (email/password only).
- No automated test suite (explicitly out of scope in the spec). Every task's verification step is a **manual check**: run the dev server and confirm the behavior, using the Browser pane where the behavior is visible. This replaces the pytest-style steps in the general planning template.
- Any verification step that would require entering a real password or submitting an account-creation/login form must be done **by the user**, never by Claude — Claude does not fill in credentials or submit auth forms, per its own operating rules. Those steps are marked **(user verifies)** below.
- Games stay playable while signed out; signing in only unlocks stat tracking.
- Required env vars: `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`.
- `game_stats` table: `user_id uuid, game_id text, stats jsonb, updated_at timestamptz`, primary key `(user_id, game_id)`, RLS restricting all access to `auth.uid() = user_id`. `profiles` table: `id uuid` (references `auth.users`), `username text unique`, `created_at timestamptz`, RLS restricting to `auth.uid() = id`.
- Flag Atlas's `stats` shape: `{ correct: number, totalResolved: number, totalCountries: number, lastPlayedAt: string (ISO) }`.

```sql
create table public.profiles (
  id uuid primary key references auth.users(id) on delete cascade,
  username text unique not null,
  created_at timestamptz not null default now()
);

create table public.game_stats (
  user_id uuid not null references auth.users(id) on delete cascade,
  game_id text not null,
  stats jsonb not null default '{}'::jsonb,
  updated_at timestamptz not null default now(),
  primary key (user_id, game_id)
);

alter table public.profiles enable row level security;
alter table public.game_stats enable row level security;

create policy "profiles are self-readable" on public.profiles
  for select using (auth.uid() = id);
create policy "profiles are self-writable" on public.profiles
  for update using (auth.uid() = id);
create policy "profiles insertable by owner" on public.profiles
  for insert with check (auth.uid() = id);

create policy "game_stats are self-readable" on public.game_stats
  for select using (auth.uid() = user_id);
create policy "game_stats are self-writable" on public.game_stats
  for all using (auth.uid() = user_id) with check (auth.uid() = user_id);

create function public.handle_new_user()
returns trigger as $$
begin
  insert into public.profiles (id, username)
  values (new.id, split_part(new.email, '@', 1));
  return new;
end;
$$ language plpgsql security definer;

create trigger on_auth_user_created
  after insert on auth.users
  for each row execute procedure public.handle_new_user();
```

```ts
import { createServerClient } from '@supabase/ssr';
import { cookies } from 'next/headers';

export async function createClient() {
  const cookieStore = await cookies();

  return createServerClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!,
    {
      cookies: {
        getAll() {
          return cookieStore.getAll();
        },
        setAll(cookiesToSet) {
          try {
            cookiesToSet.forEach(({ name, value, options }) =>
              cookieStore.set(name, value, options)
            );
          } catch {
            // setAll called from a Server Component; middleware refreshes
            // the session instead, so this is safe to ignore.
          }
        },
      },
    }
  );
}
```

- [ ] **Step 4: Write `middleware.ts`** (project root, alongside `package.json`)

```ts
import { createServerClient } from '@supabase/ssr';
import { NextResponse, type NextRequest } from 'next/server';

export async function middleware(request: NextRequest) {
  let response = NextResponse.next({ request });

  const supabase = createServerClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!,
    {
      cookies: {
        getAll() {
          return request.cookies.getAll();
        },
        setAll(cookiesToSet) {
          cookiesToSet.forEach(({ name, value }) => request.cookies.set(name, value));
          response = NextResponse.next({ request });
          cookiesToSet.forEach(({ name, value, options }) =>
            response.cookies.set(name, value, options)
          );
        },
      },
    }
  );

  // Refresh the session if it exists. No redirect on missing session —
  // games stay playable signed out.
  await supabase.auth.getUser();

  return response;
}

export const config = {
  matcher: ['/((?!_next/static|_next/image|favicon.ico).*)'],
};
```

```tsx
'use client';

import { useState } from 'react';
import { useRouter } from 'next/navigation';
import { createClient } from '@/lib/supabase/client';

export default function SignupForm() {
  const [email, setEmail] = useState('');
  const [password, setPassword] = useState('');
  const [error, setError] = useState<string | null>(null);
  const [submitted, setSubmitted] = useState(false);
  const router = useRouter();

  async function handleSubmit(e: React.FormEvent) {

          background: 'var(--surface-2)',
          border: '1px solid var(--border)',
          borderRadius: 6,
          padding: '10px 12px',
          color: 'var(--text)',

        placeholder="Password"
```

## Task 10: game-stats data layer

**Files:**
- Create: `lib/game-stats.ts`

**Interfaces:**
- Consumes: `createClient` from `lib/supabase/client.ts` (browser) — used by Task 13's client-side sync effect — and from `lib/supabase/server.ts` (server) — used by Task 11's homepage fetch.
- Produces:
  - `getGameStatsServer(gameId: string): Promise<Record<string, unknown> | null>` — reads the current user's row for `gameId` via the server client; returns `null` if signed out or no row yet.
  - `upsertGameStatsClient(gameId: string, stats: Record<string, unknown>): Promise<void>` — upserts the current user's row for `gameId` via the browser client; no-ops (resolves immediately) if signed out.

- [ ] **Step 1: Write `lib/game-stats.ts`**

```ts
import { createClient as createServerSupabaseClient } from '@/lib/supabase/server';
import { createClient as createBrowserSupabaseClient } from '@/lib/supabase/client';

export async function getGameStatsServer(
  gameId: string
): Promise<Record<string, unknown> | null> {
  const supabase = await createServerSupabaseClient();
  const {
    data: { user },
  } = await supabase.auth.getUser();
  if (!user) return null;

  const { data } = await supabase
    .from('game_stats')
    .select('stats')
    .eq('user_id', user.id)
    .eq('game_id', gameId)
    .maybeSingle();

  return (data?.stats as Record<string, unknown>) ?? null;
}

export async function upsertGameStatsClient(
  gameId: string,
  stats: Record<string, unknown>
): Promise<void> {
  const supabase = createBrowserSupabaseClient();
  const {
    data: { user },
  } = await supabase.auth.getUser();
  if (!user) return;

  await supabase.from('game_stats').upsert(
    {
      user_id: user.id,
      game_id: gameId,
      stats,
      updated_at: new Date().toISOString(),
    },
    { onConflict: 'user_id,game_id' }
  );
}
```

```tsx
import { upsertGameStatsClient } from '@/lib/game-stats';

export default function FlagAtlasPage() {
  const iframeRef = useRef<HTMLIFrameElement>(null);

  useEffect(() => {
    function handleMessage(event: MessageEvent) {
      if (event.data?.type !== 'flag-atlas-progress') return;
      const { correct, totalResolved, totalCountries } = event.data;

        totalResolved,

      style={{
        display: 'block',
        width: '100%',
        height: 'calc(100vh - 65px)',
        border: 'none',
      }}
      title="Flag Atlas"
    />
  );
}
```
